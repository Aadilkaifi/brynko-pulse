# Security policy

brynko-pulse runs on production servers, so we treat security reports as a priority.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting instead: on this
repository, open the **Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and the version (`pulse version`). We acknowledge reports
within 3 working days and keep you informed until a fix is released.

## Supported versions

Until version 1.0, only the latest release receives security fixes.
